# Windows 앱은 관리자 권한을 요구하지 않고, 상승은 perMachine 설치에만 둔다

## 결정과 근거

앱은 실행 중 권한을 올리거나 낮추는 API를 제공하지 않는다. 상승 여부는 설치 프로그램이 정한다.

상승은 설치 프로그램에만 있다. `scope: "perUser"`(기본)는 `PrivilegesRequired=lowest`로 상승 없이
설치하고, `scope: "perMachine"`만 `PrivilegesRequired=admin`으로 상승한다.

설치 마지막의 "앱 실행" 항목(선택 해제가 기본이고 조용한 설치에서는 건너뛴다)에는 두 범위 모두
`runasoriginaluser`를 붙인다. Inno Setup은 이 플래그가 없으면 프로그램을 Setup과 같은 토큰으로 실행하므로
`perMachine`에서는 앱이 관리자 권한으로 시작한다. 플래그가 있으면 설치를 시작한 사용자의 토큰으로 시작한다.
`perUser`는 상승하지 않아 결과가 같다. 테스트는 생성한 스크립트의 항목 문자열만 확인하며 Windows에서
설치 프로그램을 실행해 토큰을 측정하지는 않는다.

## 범위 밖

앱이 필요할 때 자기 자신이나 하위 프로세스를 상승 실행하는 기능(`runas`)은 제공하지 않는다. 사용자
동의 UI, 상승 프로세스와 IPC 경계, 상승 실행을 허용하는 권한 모델이 따로 필요하고 요구 사례가
확인되지 않았다. 필요해지면 별도 결정으로 다룬다.
