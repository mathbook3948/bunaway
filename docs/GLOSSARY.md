# bunaway

웹 UI와 앱 백엔드, 네이티브 호스트가 하나의 앱을 이루는 bunaway의 공통 용어다. 모든 패키지와 플랫폼에서 같은 의미로 사용한다.

## Language

### 앱 구성

**앱 패키지 (App package)**:
사용자에게 배포하는 앱의 실행 구성물 묶음이다. 네이티브 호스트, UI 자산, 앱 백엔드, 번들 런타임과 정책을 포함한다.
_Avoid_: 설치 프로그램과의 혼용

**번들 런타임 (Bundled runtime)**:
앱 백엔드를 실행하기 위해 앱 패키지에 함께 배포하는 Bun이다.
_Avoid_: 사용자 전역 Bun, 동일 프로세스 내장 VM이라는 의미의 내장 런타임

**네이티브 호스트 (Native host)**:
앱 수명주기와 창, 렌더러, 운영체제 기능 접근을 소유하는 플랫폼 측 구성 요소다.
_Avoid_: 웹 서버, 앱 백엔드

**앱 백엔드 (App backend)**:
앱 명령과 상태, 플러그인을 제공하는 신뢰된 앱 코드다.
_Avoid_: 원격 서버, WebView 코드

**코어 (Core)**:
앱 명령, 상태, 이벤트, 플러그인과 세션 수명주기를 조정하는 공통 실행 계층이다.
_Avoid_: Bun 런타임, 네이티브 호스트

**렌더러 (Renderer)**:
웹 UI를 표시하고 네이티브 호스트와 연결하는 웹 엔진 통합 계층이다.
_Avoid_: UI 프레임워크, 앱 백엔드

**뷰 (View)**:
웹 UI와 그 접근 정책을 구분하는 단위다. 창과 뷰는 같은 개념이 아니다.
_Avoid_: 창과의 무조건적인 혼용, 세션

### 호출과 수명

**명령 (Command)**:
앱이 이름과 입력, 출력 계약을 선언한 호출 가능한 작업이다.
_Avoid_: shell 명령, Host operation

**앱 상태 (App state)**:
앱 백엔드가 유지하는 앱 데이터다. 영구 저장된 데이터와는 구분한다.
_Avoid_: 영구 저장소

**이벤트 (Event)**:
앱이 이름과 데이터 계약을 선언한 알림이다. 명령의 완료 응답이나 영구 보관 메시지와는 구분한다.
_Avoid_: 명령 응답, 영구 메시지

**이벤트 구독 (Event subscription)**:
한 세션에서 특정 이벤트를 전달받기로 등록한 관계다.
_Avoid_: 영구 구독, 이벤트 이력

**세션 (Session)**:
한 뷰의 연결 수명에 속하는 협상, 요청, 이벤트 구독의 경계다. 같은 뷰라도 재연결하면 새 세션이다.
_Avoid_: 사용자 로그인 세션, 뷰 ID

**호출 컨텍스트 (Host context)**:
네이티브 호스트가 발급하고 관리하는 작업 출처와 권한 범위의 식별자다. 뷰에서 시작한 작업과 백엔드 자체 작업을 구별한다.
_Avoid_: 프런트엔드가 선언한 권한, 사용자 인증 토큰

**런타임 세대 (Runtime generation)**:
백엔드 실행의 새 수명을 이전 실행과 구분하는 식별자다.
_Avoid_: Bun 버전, 프로토콜 버전

**Host API**:
앱 백엔드가 호출 컨텍스트에 허용된 네이티브 기능을 요청하는 계약이다.
_Avoid_: 프런트엔드 SDK, 임의 OS 접근 권한

**Host operation**:
Host API에 이름과 입력, 출력 계약이 정의된 네이티브 작업이다.
_Avoid_: 앱 명령

### 권한과 확장

**정책 (Policy)**:
뷰와 백엔드 작업에 허용된 명령, 이벤트, 네이티브 기능, 데이터 범위의 선언이다.
_Avoid_: OS 권한, 기능 지원 목록

**저장 범위 (Storage scope)**:
파일 접근을 허용하는 명명된 영역이다. 앱 데이터 영역과 임시 영역을 구별한다.
_Avoid_: 임의 절대 경로, 파일 이름

**기능 지원 (Capability support)**:
해당 플랫폼에서 기능을 제공하는 수준이다. 사용자의 OS 권한 동의 상태와는 별개다.
_Avoid_: 권한 허용, 호출 권한

**OS 권한 (OS permission)**:
운영체제가 해당 기능 사용에 대해 요구하거나 부여한 권한 상태다.
_Avoid_: 앱 정책, 기능 지원

**플러그인 (Plugin)**:
명령, 이벤트, 초기화, 종료와 필요한 플랫폼, 권한을 선언하는 앱 확장 단위다.
_Avoid_: 원격 다운로드 스크립트, 자동 권한 부여

**플러그인 패키지 (Plugin package)**:
앱이 필요에 따라 설치하는 플러그인의 배포 단위다. 패키지 설치와 앱에 플러그인을 등록하는 것은 별개의 작업이다.
_Avoid_: 앱 패키지, 모든 기능을 포함하는 공통 SDK

**네이티브 플러그인 (Native plugin)**:
Host operation과 권한 계약, 플랫폼 구현을 제공하는 플러그인이다.
_Avoid_: 네이티브 호스트 자체, 일반 앱 기능 모듈

**리소스 범위 (Resource scope)**:
권한으로 접근할 수 있는 파일이나 주소 등 자원의 범위다. 대상과 비교 규칙은 해당 기능이 정의한다.
_Avoid_: 호출 컨텍스트, 저장 범위만을 뜻하는 용법

**플러그인 공통 계약 (Plugin API)**:
Core, Backend SDK와 선택 플러그인이 공유하는 중립 타입과 실행 컨텍스트다. `@bunaway/plugin-api`가 소유하며 개별 기능을 기본 등록하지 않는다.
