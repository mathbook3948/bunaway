`Schema`, `Infer`, `JsonValue`, `validateValue`는 `@bunaway/protocol`의 계약입니다.
명령의 input/output과 이벤트 payload는 같은 스키마 키워드를 사용합니다.

## 지원 키워드

| 키워드 | 의미 |
| --- | --- |
| `$schema` | 스키마 식별 메타데이터 |
| `type` | object, array, string, integer, boolean |
| `const` | 문자열, 숫자, boolean, null의 정확한 값 |
| `enum` | 문자열 값 목록 |
| `anyOf` | 적어도 한 분기의 제약을 충족 |
| `properties`, `required` | 객체 필드 스키마, 필수 이름 |
| `additionalProperties: false` | 선언하지 않은 객체 필드 거부 |
| `items`, `minItems`, `maxItems` | 배열 원소, 개수 |
| `uniqueItems` | JSON 구조적 동등성으로 배열 중복 검사 |
| `minimum`, `maximum` | 숫자 범위 |
| `maxLength` | 문자열 Unicode code point 개수 |
| `pattern` | JavaScript 정규식 검사 |

지원하는 키워드는 위 표와 같습니다. `$ref`, `format`, `oneOf`, `allOf`, `minLength`는 지원하지 않습니다.
현재 공개 Schema 타입에는 `type: "number"`가 없습니다.
제약 없는 `{}`는 유한한 숫자를 포함한 모든 유효한 JSON 값을 받습니다.

## 객체와 조합

properties에는 필드별 스키마를 적고 required에는 반드시 있어야 할 필드 이름을 적습니다.
additionalProperties를 생략하면 추가 JSON 필드를 허용합니다.
anyOf의 분기와 바깥 키워드는 함께 적용됩니다. 바깥의 객체 제약은 객체 분기에 적용되고 null 분기는 그대로 유지됩니다.

```ts
const input = {
  type: "object",
  properties: { name: { type: "string" }, age: { type: "integer", minimum: 0 } },
  required: ["name"],
  additionalProperties: false,
} as const;
```

pattern은 플래그 없이 JavaScript 정규식의 test로 검사합니다. 전체 문자열을 검사하려면 `^`와 `$`로 시작과 끝을 지정하세요.
uniqueItems는 객체의 property 순서가 달라도 같은 값으로 비교합니다. 배열은 원소 순서까지 비교합니다.

## JSON 값 제한

전송할 수 있는 값은 JSON 값입니다. 함수와 undefined, bigint, symbol, Date 및 임의 클래스 인스턴스, 순환 참조, getter는 거부합니다.
NaN, Infinity, 희소 배열과 단독 UTF-16 surrogate도 거부합니다.
순환 참조가 없다면 같은 객체를 여러 위치에서 참조하는 구조도 복사할 수 있습니다. 이때도 크기와 깊이 제한은 적용됩니다.
검증 결과는 원본과 분리된 스냅샷입니다. 복사 과정에서 getter를 실행하지 않습니다.

## validateValue와 Infer

```ts
import { type Infer, validateValue } from "@bunaway/protocol";
type Input = Infer<typeof input>;
const parsed: Input = validateValue(input, { name: "Kim" });
```

validateValue는 JSON 값과 스키마를 검증한 뒤 추론한 타입의 스냅샷을 반환합니다.
전송 크기는 메시지를 파싱하거나 직렬화할 때 별도로 검사합니다.
`parseMessage`는 원문 JSON 크기를, `serializeMessage`는 실제 직렬화 크기를 검사합니다.
스키마 위반은 ProtocolError입니다. 명령 래퍼는 입력 위반을 INVALID_ARGUMENT, 출력 위반을 INTERNAL로 바꿉니다.
