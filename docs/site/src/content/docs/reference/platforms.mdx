## 현재 앱 개발 경로

bunaway는 **Windows를 먼저 완성하고 다른 플랫폼을 같은 Bun 기반 앱 개발 모델에 맞추는 순서**로 개발합니다.
앱 개발자는 공통 `app.ts`를 작성하고, 플랫폼별 부팅은 프레임워크가 담당합니다.

| 구분 | Windows x64 | macOS arm64 | Linux, 모바일 |
| --- | --- | --- | --- |
| 네이티브 호스트 | Bun 메인 + FFI UI Worker + WebView2 | AppKit, WKWebView + 별도 Bun 자식 | 미구현 |
| CLI 앱 생성, 개발, 빌드 | 단일 창과 뷰 | 단일 창과 뷰 | 네이티브 실행 미지원 |
| 런타임 여러 창과 뷰 | 구현, 세 창 실행 검증 기록 | 미구현 | 미구현 |
| 명령, 이벤트, 저장 | 실행 검증 기록 | 실행 검증 기록 | 공통 계약과 네이티브 검증은 별개 |

`policy.json.views`가 배열이고 공통 코어에 다중 세션이 있어도,
현재 CLI에서 여러 창을 설정할 수 있다는 뜻은 아닙니다.
[창, 뷰, 정책](/concepts/views-and-policy/)을 함께 읽으세요.

## 개발자와 최종 사용자

| 대상 | 필요한 것 |
| --- | --- |
| 앱 개발자 | Bun 1.4.2, 해당 플랫폼의 네이티브 개발 도구 |
| Windows 앱 사용자 | 앱 패키지와 WebView2 런타임 |
| macOS 앱 사용자 | 지원하는 기기, OS에서 동작하는 앱 패키지 |

사용자 전역 Bun 설치는 필요하지 않습니다. 앱 패키지에 고정한 Bun을 포함합니다.
현재 공개 registry 배포는 없고 로컬 CLI, SDK tarball 설치를 사용합니다.
빌드는 대상 운영체제에서 하며 교차 빌드는 지원하지 않습니다.

## 구현과 출시 검증을 구분하기

Windows의 실제 GUI 검증에는 명령, 이벤트, 파일 권한, 다중 창, 복구, 종료가 포함됩니다.
macOS arm64에는 probe, 실제 WKWebView 단일 창 검증 기록이 있습니다.
서명, 설치, 스토어 제출까지 모두 완료한 초기 버전이라는 뜻은 아닙니다.

macOS Intel, 다중 창, Linux, Android, iOS 호스트는 현재 지원 범위에 들어가지 않습니다.
macOS ad-hoc 서명은 Developer ID, 공증, 설치 검증과 별개입니다.
현재 React, Vue, Svelte 생성 템플릿과 기본 로그, 저장 플러그인도 제공하지 않습니다.
로그, 저장 **Host API**는 이미 있으므로 플러그인 상태와 혼동하지 마세요.
