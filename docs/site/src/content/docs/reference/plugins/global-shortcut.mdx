`@bunaway/plugin-global-shortcut`를 설치하고 앱의 `plugins`에 `globalShortcutPlugin`을
등록합니다. Windows에서 제공합니다. `globalShortcut`은 화면과 앱 백엔드가 함께 사용하는
호출 API이며 `GlobalShortcut`은 키 조합 타입입니다.

```ts
import { globalShortcut, type GlobalShortcut } from "@bunaway/plugin-global-shortcut";

const shortcut: GlobalShortcut = { key: "K", modifiers: ["Control", "Shift"] };
await globalShortcut.register(shortcut);
const registered = await globalShortcut.isRegistered(shortcut);
await globalShortcut.setSuspended({ suspended: true });
await globalShortcut.setSuspended({ suspended: false });
await globalShortcut.unregister(shortcut);
```

전역 단축키는 앱 창 포커스 밖에서도 Windows가 입력을 감지합니다. 창이 없는 상태에서
계속 실행하려면 기존 `desktop.closeBehavior: "keep-alive"` 또는 트레이를 설정합니다.
단축키 등록은 앱의 마지막 창 종료 정책을 바꾸지 않습니다.

## 작업과 입력

| 함수 | 입력 | 결과 |
| --- | --- | --- |
| `globalShortcut.register` | 키 조합 | `Promise<null>` |
| `globalShortcut.registerMany` | `{ shortcuts: 키 조합[] }` | `Promise<null>` |
| `globalShortcut.isRegistered` | 키 조합 | `Promise<boolean>` |
| `globalShortcut.list` | `null` | 생성 순서의 키 조합 배열 |
| `globalShortcut.unregister` | 키 조합 | 제거했으면 `true`, 없으면 `false` |
| `globalShortcut.unregisterAll` | `null` | `Promise<null>` |
| `globalShortcut.setSuspended` | `{ suspended: boolean }` | `Promise<null>` |
| `globalShortcut.isSuspended` | `null` | `Promise<boolean>` |

목록과 boolean 결과도 Promise입니다. 키 조합은 `{ key, modifiers }`입니다.
key는 대문자 A~Z, 0~9, F1~F24 중 F12를 제외한 키, Backspace, Tab, Enter,
Escape, Space, PageUp, PageDown, End, Home, Left, Up, Right, Down, Insert, Delete입니다.
문자 위치가 아닌 Windows virtual key를 지정합니다. F12는 Windows 디버거용 예약 키여서 거부합니다.
modifiers는 Control, Alt, Shift, Super 중 하나 이상이며 중복을 거부합니다. Super는 Windows 키입니다.
결과는 Control, Alt, Shift, Super 순서로 정규화하고 입력 순서와 관계없이 같은 조합으로 조회합니다.
키 이름의 대소문자나 Ctrl 같은 별칭, accelerator 문자열을 해석하지 않습니다.

등록은 앱 전체에서 공유하며 최대 128개입니다. 이미 등록한 조합은 `BUSY`, 한 batch 안의
중복은 `INVALID_ARGUMENT`입니다. OS가 조합을 점유하거나 예약한 경우도 `BUSY`입니다.
등록 실패 시 해당 batch의 새 등록을 해제하고 이전 등록을 유지합니다.
네이티브 rollback 자체가 실패하면 `INTERNAL`이며 실제로 남은 등록을 list에 유지합니다.
앱은 조회 후 제거를 다시 시도할 수 있습니다. 다른 앱의 단축키는 조회하거나 해제하지 않습니다.

## 일시중지와 이벤트

중지하면 OS 등록을 해제하지만 앱의 등록 목록과 `isRegistered` 결과는 유지합니다.
중지 중에는 입력을 전달하지 않고 신규 등록은 `BUSY`로 거부합니다.
개별 또는 전체 제거는 중지 중에도 가능합니다. 재개하면 남은 목록을 다시 OS에 등록합니다.
중지한 동안 다른 앱이 조합을 등록하면 재개는 `BUSY`이고 전체 목록을 중지 상태로 유지합니다.
재개 중 이미 얻은 새 등록은 rollback합니다. 반복 중지와 재개는 현재 상태를 유지합니다.

Windows 해제 자체가 실패하면 중지 상태를 먼저 유지하며 입력 전달을 차단하고 `INTERNAL`을
반환합니다. 반복 중지나 재개에서 남은 해제를 다시 시도합니다. 목록은 실패한 자원의 소유권을
유지합니다. 네이티브 메시지 ID를 재사용하지 않으므로 제거하거나 중지하기 전에 큐에 들어온
입력을 새 등록에 전달하지 않습니다. 한 어댑터 수명에서 사용할 수 있는 OS ID는 49,151개이며
초과하면 `BUSY`입니다. 각 성공 등록과 재개 시도가 새 ID를 사용합니다.

`globalShortcut.pressed`의 payload는 `{ shortcut: { key, modifiers } }`입니다.
받으려는 뷰의 events에 이 이름을 허용하고 구독해야 합니다. 반복 key-down은 MOD_NOREPEAT로
억제합니다. 구독 전이나 연결이 없는 동안의 입력은 저장하지 않습니다.
키가 해제됐을 때의 이벤트는 제공하지 않습니다. 이 구현은 RegisterHotKey를 사용하며
일반 키 입력을 감시하는 키보드 hook을 설치하지 않습니다.

## 권한과 정리

각 작업은 함수와 같은 이름의 독립 Host 권한을 요구합니다. 화면 직접 호출은
`plugin.globalShortcut.register` 같은 명령도 허용해야 합니다. 허용된 작업은 앱 전체 등록에
적용되므로 대상별 접근 규칙은 앱 명령에서 검사합니다. 등록과 설치가 권한을 부여하지 않습니다.
입력이나 추가 필드 오류는 `INVALID_ARGUMENT`, 권한 없음은 `PERMISSION_DENIED`이며
미등록 작업이나 다른 플랫폼은 `UNSUPPORTED`입니다. 요청 취소는 `CANCELLED`, 기한 초과는
`TIMEOUT`입니다. 이미 완료한 동기 OS 등록은 호출 취소로 되돌리지 않습니다.

UI 어댑터가 보이지 않는 메시지 HWND를 소유하고 종료 때 모든 단축키와 HWND를 해제합니다.
OS 정리 실패도 호스트에 보고하며 나머지 정리를 시도합니다. 창별 메뉴 accelerator와 WebView
입력의 우선순위, 키 해제 알림과 다른 플랫폼 지원은 후속 작업입니다.
