```sh
bunaway doctor [directory]
```

개발 환경을 검사하고 항목마다 OK 또는 FAIL을 출력합니다. directory를 생략하면 현재 앱을 검사합니다.
모든 검사를 통과하면 종료 코드는 0이고, 하나라도 실패하면 1입니다.

## 검사 항목

| 항목 | 검사 |
| --- | --- |
| Bun | 정확히 1.4.2 |
| target | Windows x64 또는 macOS arm64 |
| configuration/policy | development 모드의 프로젝트 검증 |
| Windows 도구 | PATH의 pwsh |
| Windows WebView2 | WebView2 Evergreen 설치 여부 |
| macOS 도구 | PATH의 zsh, clang++, codesign |

외부 UI 개발 서버를 연결한 앱은 웹 프로덕션 빌드 결과가 아직 없어도 개발 환경을 검사할 수 있습니다.
HMR은 개발 서버를 실행해 확인하고, 네이티브 패키지는 build 명령으로 만듭니다.

## FAIL 처리

Bun 버전은 프로젝트가 요구하는 버전으로 맞춥니다.
Windows에는 PowerShell 7과 WebView2, macOS에는 Xcode CLT와 GUI 세션이 필요합니다.
현재 지원 대상은 Windows x64와 macOS arm64입니다.
배포할 때는 doctor 검사와 별도로 서명과 설치, 배포 동작을 확인하세요.
