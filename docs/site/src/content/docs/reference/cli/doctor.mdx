```sh
bunaway doctor [directory]
```

개발 준비를 항목별 OK/FAIL로 출력합니다. directory 기본값은 현재 앱입니다.
모든 검사 성공이면 종료 코드 0, 하나라도 실패하면 1입니다.
프로그램 API `doctor(directory)`는 같은 결과를 boolean으로 반환합니다.

## 검사 항목

| 항목 | 검사 |
| --- | --- |
| Bun | 정확히 1.4.2 |
| target | Windows x64 또는 macOS arm64 |
| configuration/policy | development 모드의 프로젝트 검증 |
| Windows 도구 | PATH의 pwsh |
| Windows WebView2 | 레지스트리에 설치된 Evergreen 탐지 |
| macOS 도구 | PATH의 zsh·clang++·codesign |

Vite 개발에서는 아직 없는 frontend 생산 출력이 허용됩니다.
doctor가 개발 서버를 띄워 HMR을 시험하거나 네이티브 패키지를 만드는 것은 아닙니다.
빌드 준비 스크립트에서 고정된 Bun·SDK·Loader 다운로드와 해시 검사를 별도로 수행합니다.

## FAIL 처리

Bun 버전은 프로젝트가 요구하는 버전으로 맞춥니다.
Windows에는 PowerShell 7과 WebView2, macOS에는 Xcode CLT와 GUI 세션이 필요합니다.
Linux에서 도구를 설치해도 현재 지원하지 않는 네이티브 target이 생기지 않습니다.
doctor 성공만으로 서명·설치·배포 검증이 완료되지는 않습니다.
