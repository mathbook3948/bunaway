```sh
bunaway package <channel> [directory] [--build]
```

네이티브 build 산출물을 채널별 배포 파일로 조립합니다.
channel은 필수이며 directory 기본값은 현재 앱입니다. `--build` 기본값은 false입니다.

## 실행 전 준비

1. `bundle.channels.<channel>`에 사용할 채널을 선언합니다.
2. 채널에 필요한 메타데이터와 아이콘, 서명 설정을 준비합니다.
3. 현재 플랫폼에서 지원하는 채널을 선택합니다.
4. 네이티브 build를 먼저 실행하거나 `--build`를 지정합니다.

Vite 앱은 웹 build를 먼저 실행하세요. `--build`는 네이티브 build만 실행합니다.
현재 플랫폼에서 지원하지 않는 채널을 선택하면 빌드를 시작하기 전에 오류를 반환합니다.

## 출력

```text
dist/<target>/packaged/
├─ <channel>/             배포 산출물
└─ <channel>-report.json  구조화된 보고서
```

원본 네이티브 build 산출물은 그대로 유지합니다.
패키징에 실패하면 이전에 성공한 출력을 유지합니다.
대상의 잠금을 얻지 못하면 보고서도 게시하지 않습니다.

CLI 종료 코드는 `report.ok`가 true이면 0, false이면 1입니다.
패키지 실행 가능 여부는 `usable`, 스토어 제출 가능 여부는 `submittable`로 확인합니다. `ok`는 패키징 작업의 성공 여부입니다.

## 현재 채널

현재 패키징할 수 있는 채널은 win-direct와 win-store-unpackaged입니다.
win-store-msix와 mac-direct, mac-store의 패키징은 아직 지원하지 않습니다.
[채널 레퍼런스](/reference/packaging/channels/)에서 기본값, 도구, 제한을 확인하세요.

프로그램 API는 `packageProject(directory, channelName, { build? }): Promise<PackageReport>`입니다.
