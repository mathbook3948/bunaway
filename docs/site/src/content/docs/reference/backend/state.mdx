`context.state`는 앱 백엔드의 메모리 JSON 저장소입니다.
`AppDefinition.state`로 초기화하고 앱 재시작 시 초기 상태로 돌아갑니다.
재시작 뒤에도 남길 데이터는 [storage.writeText](/reference/host/storage-write-text/)로 파일에 저장합니다.

## 메서드

| 메서드 | 반환값 | 동작 |
| --- | --- | --- |
| `get(key: string)` | `JsonValue \| undefined` | 저장 값의 복사본. 없는 키는 undefined |
| `set(key: string, value: JsonValue)` | `void` | JSON 값을 검증, 복사해 저장 |
| `delete(key: string)` | `boolean` | 제거. 이전에 존재했다면 true |

```ts
context.state.set("draft", { text: "초안" });
const draft = context.state.get("draft");
const removed = context.state.delete("draft");
```

## 저장 값 바꾸기

get은 저장 값의 복사본을 반환하고 set은 전달한 값을 복사해 보관합니다.
원래 객체나 반환 객체를 수정해도 저장 값은 그대로입니다. 변경할 때는 set을 호출합니다.
함수, Date, 순환 객체, undefined 등을 값으로 저장하지 않습니다.
JSON 제약은 [스키마와 JSON](/reference/schema/)를 따릅니다.

## 공유와 동시 실행

뷰와 플러그인은 같은 앱 상태를 사용합니다.
뷰별로 데이터를 구분하려면 상태 키나 명령 구현에서 범위를 나눕니다.

`get`→`await 외부 작업`→`set` 패턴은 다른 요청의 업데이트를 덮어쓸 수 있습니다.
서로 영향을 주는 변경은 직렬로 실행하거나 set 전에 최신 값을 다시 확인합니다.
트랜잭션이나 파일 저장, 재시작 후 복원은 앱에서 구현합니다.
