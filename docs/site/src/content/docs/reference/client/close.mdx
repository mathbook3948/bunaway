```ts
client.close(): Promise<void>
```

클라이언트 세션과 소유한 전송을 닫습니다. 운영체제 창을 닫거나 앱 백엔드 전체를 종료하는 API는 아닙니다.

## 사용법

```ts
window.addEventListener("pagehide", () => { void client.close(); });
```

앱 내에서 화면 컴포넌트만 교체한다면 공유 클라이언트를 닫기보다 해당 컴포넌트의 이벤트 구독을 해제하세요.
전체 페이지·연결의 수명이 끝날 때 클라이언트를 정리합니다.

## 동작

새 호출을 차단하고 준비 중인 `ready`·미완료 요청을 실패시킵니다.
활성 구독은 오류 통지를 통해 정리하고 전송의 `close()`를 호출합니다.
여러 번 호출해도 같은 완료 Promise를 사용합니다.
현재 구현은 전송의 close 실패도 클라이언트 종료 Promise에서 흡수합니다.

닫힌 클라이언트로 다시 `invoke`·`listen`을 시작하면 실패합니다.
이미 끝난 파일 저장은 되돌리지 않습니다.
페이지가 재연결되면 새 전송·클라이언트를 만들고 구독과 데이터 읽기를 다시 수행합니다.

## 관련 수명

호스트는 탐색·렌더러 복구·창 닫기 때 세션을 폐기합니다.
클라이언트 정리는 호스트가 OS 자원을 실제 회수했다는 확인과는 다릅니다.
[세션과 수명주기](/guides/sessions-and-lifecycle/)에서 각 단계의 책임을 확인하세요.
