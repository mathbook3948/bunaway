기능을 처음 사용한다면 [명령과 이벤트 가이드](/guides/commands-and-events/)부터 읽으세요.
아래 레퍼런스는 함수별 인자, 반환값, 기본값, 권한, 오류, 수명을 설명합니다.

## 프런트엔드

| API | 용도 |
| --- | --- |
| [createClient, ready](/reference/client/create-client/) | 클라이언트 생성, 협상 |
| [createWebViewTransport, Transport](/reference/client/transport/) | 네이티브 브리지 연결 |
| [invoke](/reference/client/invoke/) | 명령, 취소, deadline |
| [listen](/reference/client/listen/) | 구독, 이벤트 순서, 해제 |
| [capabilities](/reference/client/capabilities/) | 플랫폼 기능, OS 권한 조회 |
| [close](/reference/client/close/) | 대기 요청, 구독, 전송 종료 |

## 백엔드

| API | 용도 |

| [PluginDefinition](/reference/backend/plugins/) | 등록, 의존성, setup, 정리 |
