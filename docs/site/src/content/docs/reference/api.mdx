기능을 처음 사용한다면 [명령과 이벤트 가이드](/guides/commands-and-events/)부터 읽으세요.
각 레퍼런스에서는 함수의 인자와 반환값, 기본값을 설명합니다. 필요한 권한과 오류 처리, 요청이나 구독이 유지되는 기간도 함께 확인할 수 있습니다.

## 프런트엔드

| API | 용도 |
| --- | --- |
| [invoke](/reference/client/invoke/) | 백엔드 작업 요청과 결과, 취소, deadline |
| [listen](/reference/client/listen/) | 구독, 이벤트 순서, 해제 |
| [capabilities](/reference/plugins/capabilities/) | 등록된 기능 지원, OS 권한 메타데이터 조회 |
| [createClient, ready](/reference/client/create-client/) | 기본 클라이언트 사용과 앱 정의의 타입 추론 |
| [close](/reference/client/close/) | 공유 연결의 명시적 종료 |

사용자 정의 연결은 [createWebViewTransport, Transport](/reference/client/transport/)에서 설명합니다.

| [defineApp, AppDefinition](/reference/backend/app-definition/) | 기능 모듈 조립과 앱의 default export |
| [defineModule](/reference/backend/module/) | 기능별 명령과 이벤트 등록 |
| [command](/reference/backend/command/) | 입력과 출력 스키마와 handler |
| [storage, log, capabilities](/reference/backend/host-api/) | 저장, 로그, 기능 조회 직접 호출 |
| [windows](/reference/host/windows/) | 창 생성과 재생성, 표시, 크기와 위치, 전체화면, 닫기 확인 |
| [CommandContext, host.call](/reference/backend/context/) | 원래 요청의 신호, 권한 |
| [state.get, set, delete](/reference/backend/state/) | JSON 메모리 상태 |
| [events.emit](/reference/backend/events/) | 발행 대상, 권한, 전달 |
| [PluginDefinition](/reference/backend/plugins/) | 등록, 의존성, setup, 정리 |

## 설정과 CLI

- [bunaway.json](/reference/configuration/), [policy.json](/reference/policy/), [bundle](/reference/packaging/configuration/)

`bunaway --help` 또는 `bunaway help`는 사용법을 출력하고 종료 코드 0으로 끝납니다.
하위 명령을 생략해도 사용법을 출력합니다. 알 수 없는 명령이나 옵션, 추가 인자를 전달하면 오류를 반환합니다.
