```ts
context.host.call("capabilities.get", null): Promise<Capabilities>
```

앱 백엔드에서 현재 플랫폼 기능 정보를 조회합니다.
UI에서는 예약 명령을 이용하는 [client.capabilities](/reference/client/capabilities/)를 사용합니다.

```ts
const capabilities = await context.host.call("capabilities.get", null);
```

## 응답 필드

| 필드 | 필수 | 값, 제약 |
| --- | --- | --- |
| `name` | 예 | 영숫자, `_ . : -`, 1–128자 |
| `support` | 예 | supported, experimental, unsupported |
| `permission` | 예 | granted, denied, prompt, not-required, unknown |
| `reason` | 아니요 | 문자열, 최대 1,024자 |

최대 256개이며 같은 name의 중복을 거부합니다.
현재 Windows는 storage.readText, storage.writeText, log.write, capabilities.get을
supported, not-required로 보고합니다.

## 권한 의미

support는 플랫폼의 구현 상태이고 permission은 현재 OS 권한 상태입니다.
조회는 현재 상태를 반환하며 정책 변경이나 OS 권한 요청은 실행하지 않습니다.
실제 작업을 호출하면 활성 컨텍스트와 정책을 다시 검사합니다. 파일 범위와 명령 호출 권한은 뷰 정책으로 정합니다.

입력은 반드시 null입니다. 잘못된 입력은 `INVALID_ARGUMENT`,
취소는 `CANCELLED`, 유효하지 않은 Host 응답은 바인딩 계층에서 `INTERNAL`로 처리합니다.
