## 현재 사용할 수 있는 범위

Windows x64를 우선으로 개발합니다. **CLI 생성 앱은 현재 단일 창과 뷰**를 사용합니다.
Windows 런타임에는 여러 창과 뷰별 정책이 구현돼 있고, macOS arm64 호스트는 단일 창과 뷰입니다.
공개 npm 배포는 아직 없어 첫 앱은 로컬 tarball 묶음으로 생성합니다.

[지원 범위](/reference/platforms/)에서 구현, 실행 검증과 남은 작업을 확인하세요.
[설계와 검증 자료](/reference/design/)는 기존 ADR, 계약, 실행 기록으로 이어집니다.
