## 현재 사용할 수 있는 범위

Windows x64를 먼저 개발하고 있습니다. **CLI로 만든 앱은 창 하나와 뷰 하나를 사용합니다.**
Windows 런타임에는 여러 창을 여는 기능이 구현돼 있습니다. macOS arm64 호스트는 창 하나를 지원합니다.
공개 npm 배포는 아직 없어 첫 앱은 로컬 tarball 묶음으로 생성합니다.

플랫폼별 구현 상태는 [지원 범위](/reference/platforms/)에서 확인하세요.
