앱 개발에는 HTML, CSS, TypeScript의 기본 지식과 **Bun 1.4.2**가 필요합니다.
현재 Windows를 우선으로 개발합니다. Windows 앱은 Windows에서, macOS 앱은 macOS에서 빌드합니다.

## Windows x64

- Bun 1.4.2.
- PowerShell 7 (`pwsh`).
- WebView2 Evergreen 런타임.
- 실제 창을 열 수 있는 GUI 세션.

Windows 호스트는 Bun FFI이므로 앱 개발에 C++ 컴파일러를 요구하지 않습니다.
앱 설치 파일 `win-direct`, `win-store-unpackaged`를 만들 때는 Inno Setup 6.3 이상이 필요합니다.
실행 파일에 서명하려면 Windows SDK의 signtool과 서명 인증서를 준비합니다.
채널별 도구는 [패키징 채널](/reference/packaging/channels/)에서 확인하세요.

## macOS arm64

Bun 1.4.2, Xcode Command Line Tools, GUI 세션이 필요합니다.
현재 호스트와 CLI는 macOS 14 이상인 Apple Silicon 기기를 지원합니다.
Intel 기기와 여러 창은 아직 지원하지 않습니다.
개발 빌드는 ad-hoc으로 서명합니다. 배포용 Developer ID 서명과 공증은 따로 준비해야 합니다.

## 환경 확인

앱을 만들고 의존성을 설치한 뒤 앱 폴더에서 실행합니다.

```sh
bun --version
# vanilla
bun run doctor
# vite
bun run bunaway doctor
```

Linux에서는 문서 사이트를 실행하고 공통 타입과 계약을 검사합니다.
네이티브 앱 호스트는 아직 없으며 실제 창 동작은 Windows나 macOS에서 확인합니다.

## 문서 사이트와 최종 사용자

문서 기여 도구에는 Bun 외에 Node.js 22.12 이상이 필요합니다.
Node.js는 Astro 문서 도구를 실행할 때 사용합니다.
최종 앱은 번들 Bun을 사용합니다. Windows 사용자는 WebView2가 있어야 합니다.
