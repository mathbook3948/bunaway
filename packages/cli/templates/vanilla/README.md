# Bunaway + Vanilla TS

A starter for Bunaway desktop apps with HTML, CSS, and TypeScript.

Requires [Bun 1.4.2](https://bun.sh).

## Get started

```sh
bun install
bun run doctor
bun run dev
```

Edit `src/` for the UI and `src-bunaway/src/` for the backend.

## Build

```sh
bun run build
```

The desktop app is written to `dist/`.

[Documentation](https://github.com/mathbook3948/bunaway/tree/main/docs)
